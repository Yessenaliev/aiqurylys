# Опись функций основного сайта ai-qurylys.kz (снята 16.11.2026)

Снято под входом владельца на пробном доступе, только чтение. Аккаунт пустой (0 проектов), поэтому внутренности проекта (график, склад, люди) описаны по подсказкам страниц. Это основание для пересборки прототипа: всё ниже должно быть в прототипе, ничего не терять, только сделать понятнее.

## Общий каркас (на каждой странице)
- Нижняя/верхняя панель: Главная, Проекты, Создать, Задачи, Ещё. Поиск (Ctrl K), колокольчик, профиль.
- В шапке каждого раздела: **FAQ** (с привязкой к странице), **Как пользоваться разделом** (4 шага), **Читать полностью** (описание), **Спросить AIQurylys: <помощник раздела>**.
- Помощники по разделам: Документовед, Инженер по себестоимости, Инженер по контролю объёмов, Финансист, Снабженец, Начальник участка, Прораб/Мастер участка, Инспектор техники, Архитектор, Помощник по тендерам, Наставник по работе в системе.
- Проект выбирается один раз во вкладке «Ещё» и действует во всех разделах («Проект не выбран» на каждой странице).
- Плашка пробного доступа над разделом: «каждый раздел можно попробовать один раз, файлы до 2 МБ (расчёт — до 15 МБ)».

## Главная (/welcome)
«Начало работы», 3 шага, чеклист «0 из 3 готово»: рассчитать раздел, рассчитать остальные, собрать свод проекта. Кнопка «Загрузить файлы раздела». Для рабочего аккаунта: что требует решения, цифры дня, быстрые действия.

## Проекты (/projects)
Список, «Сроки по всем проектам», фильтры Все / Требуют внимания / По графику / Завершённые, поиск «Найти проект». **Добавить проект** (форма): название, адрес, роль (генподрядчик / субподрядчик), заказчик/сторона, шифр ПСД и состав, описание; «Создать проект»; «Из папки или архива .zip» (по подписке). Внутри проекта: график, площадка, объёмы, документы, файлы, деньги, склад, техника, люди.

## Задачи (/my)
Вкладки Мои / Выданные мной / Команда. **Выдать задание**: что сделать, объём, единица, срок, кому (сотрудник, есть ли бот), примечание.

## Себестоимость (/estimate/…)
Вкладки: **Расчёт по ПСД**, **Свод проекта**, **Проверка КП от подрядчика**, **Коммерческие предложения**.
- Расчёт: список «Расчёты компании», «Новый расчёт»: что считаем (проект или «без сохранения»), дата начала работ, выбор файлов (PDF, DWG, DXF). Результат: Excel/Word/PDF, «Подобрать цены», «Сформировать КП», «Передать дальше».
- Свод проекта: все разделы проекта в один Excel.
- Проверка КП: шаги КП → Листы → Замечания; загрузка .xlsx, «Что не подойдёт», «Открыть листы»; результат: список замечаний и файл с листом «ИСПРАВЛЕНИЯ».
- Коммерческие предложения: строятся из сохранённого расчёта, наценка и условия, версии.

## Сверка акта с проектом (/volume-check)
Вкладки: Акт подрядчика, Сравнение КП с проектом. «Проверить акт» (акт + договор или проект), список проверенных актов с сохранёнными правками. Сравнение: проект + КП подрядчика (любой формат), порог расхождения в % (по умолчанию 10), результат в деньгах.

## Инженер тех документации (/documents)
Вкладки: **Сейчас**, **По этапам** (140 видов), **Сделанные**, **Схема площадей**, **Комплектность**; ссылки «Файлы проекта», «Справочник». «Сейчас»: готово к скачиванию, «Сделать документ» по событию (скрытые работы выполнены, поступил материал, простой/дефект/нет фронта, закрытие месяца, другой документ).
Мастера документов (4 шага, «Все шаги на одной странице», «Взять из Файлов проекта»):
АОСР (проект, участники, работы, отклонения); пакет АОСР (+ добавить акт, скачать .zip); акт передачи площадки / геодезической проверки; дефектный акт (комиссия, дефекты, материалы с ценами из каталога, списание или срок); акт простоя техники (часы, тариф, итог к возмещению); акт 2В (стороны, работы и разделы, НДС 16 % / 12 %, подписи); Р-1 и счёт на оплату (реквизиты, кому, работы, два файла Excel); пакет АВР в Excel (договор, период, ведомость, подписи); схема площадей отделки (PDF ПСД, этажи).
Файлы проекта: альбомы, ведомости, договоры, акты по разделам, версии, раздел определяется по имени файла.

## Начальник участка (/site-chief)
Вкладки: Сегодня, График, Склад, Техника, Подрядчики; «Сроки по всем проектам»; «Сводка по готовому графику». «Выдать задание», «Принять / Вернуть» с замечанием, акт после скрытых работ.
Подрядчики: свои, «В интернете» (вид работ + город), «Из своих договоров»; фильтры Все / Работали / Кандидаты / Без контактов, виды работ, города, поиск, «Добавить подрядчика», «Найти новых подрядчиков».

## Прораб/Мастер (/master)
Вкладки: Мои работы, Материалы и нормы, Склад, Техника. День, «Заполнить отчёт» (люди, техника, фото, чего не хватает), «Оформить наряд» (Word), вход в Telegram-бот. Материалы и нормы: ведомости материалов из альбома (загрузка, «или папку проекта»), вопросы по расходу и технологии (примеры вопросов), «Отправить».

## Инспектор техники (/equipment)
Реестр, учёт ТО, напоминания, карта, «Дела на сегодня», «Деньги». «Импорт списком», «Добавить технику», «Записать» (заправка, моточасы, ТО, поломка). Фильтры Все / С делами / Активна / На ремонте / Списана. Доходы и расходы: период с/по, тип (все / доходы / расходы), категории: доходы, топливо, ремонт, ТО, запчасти, зарплата и эксплуатация, прочее; доход, расход, разница.

## Финансист (/finance)
Вкладки: По проекту, Бюджет, БДР, БДДС, По всем проектам, Отчёты 1С, Приход материалов. «Прогноз себестоимости», «Записать» (реестр расходов), «Подключите 1С». Бюджет: исходный = себестоимость принятого расчёта, факт = платежи из реестров, обязательства = договоры, остаток считает сервер.

## Снабженец (/supplier)
Вкладки: Панель управления, Поиск цен, Поставщики, Запросы и ответы. Панель: заявки с проектов, ответы поставщиков, не хватает на проектах, «Сейчас сделать» (прайсы старше 5 месяцев), быстрые действия. Поиск цен: материал, единица, «Найти цены». Запросы: «Новый запрос», «Проверить почту сейчас», почта компании (адрес + пароль приложения, «Проверить и подключить»), журнал с поиском, фильтры «Ждут решения / Все», период, сортировка, возраст цен по группам.

## Юрист (/legal)
Вкладки: Составить договор («Новый договор»: подряд, проектирование, поставка, услуги), Проверка договора (Word/PDF, скан до 2–3 минут; «Составить протокол разногласий без загрузки»), Письма и претензии (Претензия / Ответ на претензию; файл договора или из Файлов проекта; причина: не оплатили, сорвали срок, брак, другое; сумма; описание; «Написать претензию»; «заполнить вручную»), Чат с юристом (примеры вопросов).

## Тендеры и закупки (/marketing)
Лента тендеров (источники: госзакупки работы/товары/услуги, Bnect, Tizilim, Mitwork, Caspy, ETS, EurasianTech, mp.kz; загрузка раз в день), «Проверить своё объявление» (текст или документ, «Подставить пример», «Разобрать объявление»), «Ваша тендерная документация», «Спрос по регионам» (регион + фокус, ИИ-разбор, хранится 3 дня).
Тендерная документация / Реквизиты компании (одна форма): загрузка документов, название, БИН, IBAN, категория лицензии, виды работ, оборот и обороты по годам, цель (обеспечение заявки), опыт лет, штат, ключевой персонал, техника, сертификаты, «Добавить договор», адрес, банк, БИК, КБЕ, руководитель, должность, основание, телефон, почта; «Сохранить»; «Скачать список для бухгалтерии (Word)»; «Что сознательно не запрашиваем».
